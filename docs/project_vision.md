## Purpose

The purpose of this project is to build a professional fixed-income analytics toolkit initially focused on Argentine Treasury Bills (Letras).

The project is intended to:

- Automate financial calculations.
- Reduce operational errors.
- Document Argentine market conventions.
- Produce transparent and verifiable pricing and yield calculations.
- Build reusable financial calculation modules.

The long-term objective is to evolve into a modular fixed-income platform capable of supporting multiple instrument types, portfolio analytics, market data integration, and professional reporting.
